# 映颜应用图标

`mark.png` 是 Android 与 Windows 共用的透明底母图；`app.ico` 是 Windows 多尺寸图标（16–256px）。Android 自适应图标使用同一母图缩至 512px，搭配 `#10251F` 背景；支持圆形裁切和 Android 13 主题图标。

图案：薄荷绿折叠丝带构成播放三角，配一颗美颜星光。使用内置 image_gen 生成；打包转换仅做 PNG 缩放和 ICO 格式转换。图标资产随本项目采用 MIT 许可。

最终生成提示词：

Clean geometric vector-like finish, subtle restrained depth, strong silhouette readable at 24px. Palette mint #A5EAD3, deep teal #388B75, pale mint highlights. Square canvas, centered symbol, all artwork within central 66% for Android adaptive icon safety. True transparent background. No text, no letters, no surrounding card or mockup, no extra particles. Intended shared Android and Windows application icon.
