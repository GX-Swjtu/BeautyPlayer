## 性能和同步

全效果参数：磨皮 60、美白 30、冷暖 12、色调 8、瘦脸 50、大眼 40、口红 60、腮红 40。默认用户设置仍全部为零。视频处理尺寸未降低，人脸检测使用最长边 640 的副本。

| 素材与测试 | 呈现帧率 | 平均处理耗时 | 结论 |
|---|---:|---:|---|
| 1080×1920 / 30 fps，600 秒 | 平均 29.77，中央值 30 fps | 23.14 ms | 本机达到接近满帧的实时美颜 |
| 2160×3840 / 23.976 fps，30 秒 | 平均 16.29，中央值 17 fps | 56.99 ms | 保留原始尺寸，但未达到原片满帧 |
| 1920×1080 / 30 fps，同步片 60 秒 | 平均 29.94 fps | 24.09 ms | 软件管线音频与视频时间戳差 17.33–58.67 ms |

帧率统计排除前五秒启动阶段，长测还排除暂停区间。长测期间还运行过短时验收用例，数据反映本机当时的实际负载。4K 吞吐量未满足满帧，不以丢帧或原图回退冒充达到实时指标。

音频时间戳来自 QAudioBufferOutput。Qt 的音频缓冲时间戳跨循环累加、视频时间戳重置，因此按媒体周期归一化比较，同时保留原始差值。这不是扬声器声学延迟或显示器扫描延迟测量；声学实测未执行。

## 修复与复测

- 修复旧版 raw input 的像素步长适配、PBO 前一帧错配、NVIDIA 白平衡 shader 编译失败和中文资源路径崩溃。
- 修复后重新完成 600 秒长测；长测之后仅增加资源路径编码检查、诊断截图异步保存与构建资源复制串行化，没有改变滤镜算法或帧调度。最终构建补测了图像回归、中文目录搬迁、独立打包、4K 和 60 秒同步片。
- 所有测试模式均不读写用户美颜设置。测试用本地 HTTP 服务已停止。

汇总数据：`artifacts/verification-summary.json`。原始 JSON、日志和截图保存在 `artifacts`；公开素材来源、许可及配套库说明见根目录 `THIRD_PARTY_NOTICES.md`。
